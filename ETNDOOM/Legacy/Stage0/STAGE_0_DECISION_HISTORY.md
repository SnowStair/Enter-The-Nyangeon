### B.3 Future WAD Collision / 后续 WAD 碰撞研究

以下为阶段 1 及以后研究方向，不是阶段 0 的开发任务或开工条件。

这是矩形平地图的阶段 0 原型，不是“所有 WAD 墙线都生成实体墙”的 DOOM 碰撞实现。后续加载 DOOM 地图时，几何应以 `VERTEXES` / `LINEDEFS` 及其 `SIDEDEFS`、`SECTORS` 引用为依据；单面线、双面线开口、阻挡标志与实体高度需分别判定，`BLOCKMAP` 只是邻域查询索引。可研究由 Godot 承担确定的平面墙体阻挡，由独立空间规则按实体的平面位置、底部高度、半径、高度和标志判断双面线开口、台阶、落差及弹丸通行；以 DOOM 的 `P_LineOpening`、`PIT_CheckLine`、`P_TryMove` 等为规则对照，不把素材纹理当作阻挡依据，也不要求初期嵌入原版 C 碰撞代码。这是后续研究方向，具体 Godot 物理与规则层的分工仍须在阶段 1 决定，不能把阶段 0 的矩形外框或静态墙直接升级为完整 WAD 碰撞规则（参见 `E:/DOOMSourceCode/DOOMSourceCode/DOOM-map-analysis.md` §1.5、§3.3-3.6、§4.4）。
